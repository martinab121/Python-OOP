# Python OOP – SoftUni (2020)

Work from the [Python OOP course at SoftUni (February 2020)](https://softuni.bg/trainings/2497/python-oop-february-2020#lesson-14249).

This repository currently contains a single file:

| File | What it practises |
|---|---|
| [Encapsulation Exercise](Encapsulation%20Exercise) | Encapsulation – a `Zoo` class with private attributes (`__budget`, capacities) and methods for adding animals, hiring/firing workers, paying salaries and reporting status |

The file holds only the `Zoo` class body; the supporting `Animal` / `Worker` classes from the exercise are not included, so it is meant as a code sample to read rather than run.
